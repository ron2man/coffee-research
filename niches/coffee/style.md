# Coffee Fieldnotes style guide

The writer agent receives this file. The lint (M4) and the post judge enforce it. Quality reference: [content/reference/bambino-grinder-picker.html](../../content/reference/bambino-grinder-picker.html).

## Voice

- Open with the recommendation in the first paragraph, in a human voice. "Get the X" beats "There are several options to consider."
- Argue one clear opinion. Add a "When I'd choose differently" section.
- Always include a "don't buy / keep yours" path, with a test the reader can run on what they already own.
- Prefer a tool, decision rule or diagnosis over a spec table.
- No hedging chains. State what is unknown once, plainly.

## Honesty

- Never write "we tested", "in our testing", "hands-on" or "we measured" unless the post carries human-supplied data with an author and a date.
- Attribute other people's tests to them ("a reviewer for X ran two blind tastings"), and say how much weight they deserve.

## Links and sources

- At most **2 inline links** in the body.
- All sources go in a collapsed "How this guide was put together" section at the end. It says what we did and did not do.
- Factual statements map to claim IDs in `claims.json`. Evidence lives there, not in the prose.
- Affiliate URLs are never written into post text. The layout renders offers and the disclosure.

## Patterns to avoid

- "In conclusion", "Ultimately", "It's worth noting", "When it comes to".
- Every section built from the same template (intro sentence, three bullets, summary).
- Repeating the recommendation as a summary after every section.
