# ECM Classika III vs Classika PID: How to identify the model and check a used PID’s cold start

ECM lists the **Classika III as CM100024-00** and the **Classika PID as CM100003-00**. If a listing just says “Classika”, ask for the item number and a photo of the front controls. The III has an OLED display and a dial you turn and press. I’d buy the cheaper used PID if the seller can show that the exact machine makes its first espresso within the time I normally have. If it misses that window, I’d ask for the same cold-start demonstration on the III before paying more. [Classika III catalogue](https://www.ecm.de/en/products/classika-iii/) · [Classika PID catalogue](https://www.ecm.de/en/products/classika-pid/)

## Confirm the machine in the listing

Ask for a photo of the rating plate and confirm the voltage, frequency and plug on the unit you’ll receive. ECM’s manuals list **230 V, 50 Hz** for the documented UK PID and **230 V, 50/60 Hz** for the III in the group of markets that includes the UK. For a used PID, keep the model and serial details handy when asking which manual applies. [Classika PID manual, §3.2](https://www.ecm.de/wp-content/uploads/2025/04/BA_Classika_-PID_2412-web.pdf#page=24) · [Classika III manual, §14](https://www.ecm.de/wp-content/uploads/2026/08/BA_Classika-III-web.pdf#page=142)

## Ask the seller to show the used PID’s first shot

1. **Confirm the manual for that unit.** Ask the seller which manual applies and whether it describes Fast Heat-Up. If they’re unsure, ask them to check with ECM using the unit’s details. [Classika PID manual, §6.1](https://www.ecm.de/wp-content/uploads/2025/04/BA_Classika_-PID_2412-web.pdf#page=26)
2. **Start with the machine fully cold.** Ask for a live demonstration or a continuous video that starts before switch-on. Start timing at power-on and keep the display in view.
3. **Watch the flush and the first espresso.** If the unit uses the documented Fast Heat-Up sequence, the seller should flush when the display shows `FLU` and continue until `rdY/Go` appears. Ask them to show the first shot and record the elapsed time from switch-on until the espresso is in the cup. For a unit with a different sequence, have the seller follow its own manual. [Classika PID manual, §6.1](https://www.ecm.de/wp-content/uploads/2025/04/BA_Classika_-PID_2412-web.pdf#page=26)

## Use the advertised times to decide what to test

ECM advertises **6.5 minutes** to brew readiness for the Classika III and **11 minutes** for the currently listed Classika PID. Those figures describe advertised readiness. The elapsed time through the first shot on the machine you’re considering is what you’ll compare with your morning routine. [Classika III catalogue](https://www.ecm.de/en/products/classika-iii/) · [Classika PID catalogue](https://www.ecm.de/en/products/classika-pid/)

If the used PID takes too long and you’re considering the III, ask the III seller to time the same switch-on-to-first-shot process. The III manual specifies a five-second flush if the display prompts `MAKE A FLUSH`. Ask the seller to include it if prompted. [Classika III manual, §9.8.1](https://www.ecm.de/wp-content/uploads/2026/08/BA_Classika-III-web.pdf#page=112)
